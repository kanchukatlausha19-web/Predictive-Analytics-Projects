## Project 1: Predicting Default of Credit Card Clients
- Dataset: UCI Credit Card (30,000 observations)
- Tools: R, ggplot2, caret, randomForest
- Models: Logistic Regression, Decision Tree, Random Forest
- Best Model: Random Forest (AUC = 0.78)
- Key Finding: PAY_0 (recent repayment status) is the strongest predictor of default
